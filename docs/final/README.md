# Final Documentation Package

This folder contains the active documentation for the Food Delivery System. The project's final report source and submission checklist live in the submission folder, and legacy draft/checklist files have been archived to keep the final documentation package uncluttered.

| File | Purpose |
|---|---|
| `DATA_STRUCTURES_DOCUMENTATION.md` | Custom data structure documentation |
| `ALGORITHMS_DOCUMENTATION.md` | Algorithm documentation |
| `DATABASE_AND_DATASET_DOCUMENTATION.md` | Dataset, mapping, and JDBC documentation |
| `TRACE_TABLES_AND_DEMO_EVIDENCE.md` | Summary of committed evidence outputs |
| `TESTING_AND_VALIDATION.md` | Final Maven verification and compliance notes |
| `DEMO_SCRIPT.md` | Presentation/demo script |
| `TEAM_CONTRIBUTIONS_AND_DEVELOPMENT_LOG.md` | Development history and team-confirmed individual contributions |
| `DSA_CORRECTNESS_EVIDENCE.md` | Trace tables, proof sketches, counterexamples, and edge-case evidence |
| `AI_USE_ACKNOWLEDGEMENT.md` | Truthful acknowledgement of AI-assisted drafting and evidence checking |
| `submission/` | Final submission package with the cover sheet, final report source, DOCX/PDF exports, and supporting performance artifacts |
