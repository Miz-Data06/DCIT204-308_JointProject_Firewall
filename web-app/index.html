What Happens Behind the Button

1

Validate input

The backend checks locations, urgency, category, capacity, and deadline.

2

Persist request

A `WEB###` request is saved through the existing JDBC repository.

3

Run algorithms

Dijkstra finds the fastest route; greedy assignment checks eligible riders.

4

Return evidence

The confirmation shows the real route, effective time, priority score, and assignment.

This web app is optional extra functionality. The Java console application remains the official required demo.
