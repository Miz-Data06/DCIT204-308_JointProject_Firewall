# Optional Web Demo Dashboard

This folder contains an optional static web demo for the Firewall Food Delivery DSA project.

It is presentation support only. The Java console application remains the official runnable project interface.

## Open Locally

Open `web-demo/index.html` directly in a browser.

No server, npm install, framework, or internet connection is required.

## Optional Local Server

From this folder:

```powershell
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Contents

- `index.html`: dashboard markup.
- `styles.css`: responsive dashboard styling.
- `app.js`: local data rendering, filters, and navigation behavior.
- `assets/performance_graphs/`: copied performance PNGs from the final submission docs.

All displayed algorithm results come from committed evidence files and final documentation.
